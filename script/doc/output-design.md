# 应急脚本输出目录、命名与大本差核对表

最后更新：2026-10-13（按用户最新反馈拆分大本差列）。

已确认 script/data/ 保存 JSON、script/results/ 保存两份 CSV，结果带排序代号后缀；第二份把进攻和防御拆成两组列，先列各轮进攻、再列各轮防御。全部文件以来源完整赛季标识的日期统一年_月_日，同一届更新原归档，不取首场战争 startTime 替代日期。

## 1. 已明确的目录与命名

查到有效联赛／目标战争资料后及时保存 JSON 归档，路径为：

~~~text
script/data/部落名称_部落标签_年_月_日.json
~~~

第一份为成员排名信息，第二份为大本差详细核对，均为 CSV，放在 script/results/。按最新增加起始日的命名结构为：

~~~text
部落名称_部落标签_年_月_日_排名信息_ABC.csv
部落名称_部落标签_年_月_日_大本差详细信息_ABC.csv
~~~

ABC 表示本次按 A B C 排序；输入 D A B 时使用 DAB，保留实际优先级，不按字母重新排列。来源归档的文件名不带排序序列，因为相同战绩可以用不同排序生成结果。

排序输入直接回车已确认采用 A B D C F，因此默认两份 CSV 的排序后缀为 ABDCF。

结果格式已确认 CSV／.csv，来源归档使用 .json。统一年_月_日已确认，例如完整赛季标识 2024-12-02 对应 2024_12_02。不按首场战争 startTime 替换来源日期，也不能自行补日为 01。

年、月、日取自实际选定的完整联赛标识，不能仅用系统日期。显式参数为 YYYYMM，无参数当前年月；内部仍保存完整标识和真实部落名称／标签。名称含不支持的字符时，使用跨平台的文件名处理，归档保留原值。

如果官方来源只给年月，完整日期必须经已验证的来源对应关系补足，不能凭猜测造日。身份尚未确认时保全已经取得的标签和有效资料，并明确待识别状态；无法核实完整身份就不能宣称已按确定日期完成正式归档或将另一届写入该文件。

取得部分有效资料时，也按既定及时落盘要求保留已取得的 JSON 与缺失状态，不等全部战争成功才写文件。完全未取得所需联赛资料时明确报告失败，不创建冒充完整联赛的归档或排名。

## 2. 第一份：排名信息

延续成员整届汇总与按所选规则排名的用途。计算沿用正式规则，排序按用户输入的 A～F 序列降序。所有已选排序项都相同的成员显示并列名次，采用竞赛排名（例如 `1、2、2、2、5`）；玩家标签升序只决定并列成员的行顺序。结果能辨识成员、指标值、所选序列、数据时间、完整性和排名状态。

必要数据缺失时可以保留已有汇总与缺失信息，但排名与补分暂停，不因文件名含“排名信息”就强行给出有效排名。

## 3. 第二份：大本差详细核对

用户将第二份结果明确为核对表，替代此前计划的完整逐轮成员明细结果文件。主内容包括：

- 成员名称。
- 成员大本营等级。
- 常规七轮拆分为十四列：先按轮次排列七列进攻大本差，再排列七列防御大本差，用于核对实际计算依据。

按该届全部报名成员列行，以玩家标签识别身份；建议保留成员标签，避免同名成员无法区分。进攻组和防御组分别按轮次升序排列；常规七轮为十四列。特殊形式仍遵循该届实际轮次，不以七轮覆盖或截断其他轮次。

列标题注明轮次和进攻／防御类型，格子内容不再重复写类型，也不把两者合并为一个数。单次记录直接显示大本差，例如“+1”；同轮多次记录保留全部差值并显示合计，供用户核对 C／F，例如“+1、+2（合计 +3）”。

- 进攻大本差：目标大本减成员当次战争大本。
- 防御大本差：对手进攻者大本减成员当次战争大本。
- 大本差来自战争历史快照，不用当前玩家资料替换。
- 同轮多次记录需能够核对全部实际差值与用于 C／F 的合计，不能仅保留杯分最差的一次防御作为 F 的依据。
- 真实大本差为 0、未出场、未进攻／未被攻击和采集缺失需要明确区分；未知信息不能显示成数值 0。单条 `+0` 只显示一次，不额外重复为“合计 +0”。
- 同届成员升级导致多轮大本不同，单一“成员大本”列必须明确表示等级变化，逐轮实际快照在归档中保留；不能用当前等级掩盖历史差值依据。

完整逐轮战绩继续在 JSON 保存，可用于离线核验和重算；不默认增加第三份完整逐轮 CSV。

## 4. 重名与同月多届

用户已确认目标月全部联赛分别导出，完整赛季日期统一年_月_日，同一届重复采集更新原归档。不同完整联赛不互相覆盖。相同日期与排序对应本届结果，更改序列生成不同后缀。同月两届通常产生两份 JSON 和四份 CSV，不把两届合并为一套结果。

不只凭文件名判断归档身份，补采需核对 JSON 内部的部落、完整联赛和战争对应关系。部落改名也不能被解释成新联赛或使其他归档被错误覆盖。

## 5. 验收补充

实施 agent 验证输出位于指定目录、文件名带实际排序顺序、年_月属于正确目标，归档与结果格式／扩展名一致。核对表覆盖完整报名名单和实际轮次；包含真实零差、缺失、多次攻击、防御及大本变动样例，且可与归档中的战争等级和 C／F 统计核对。
